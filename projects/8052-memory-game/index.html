Four-MCU Memory Game

A physical two-player game. Four 8052 microcontrollers coordinate input, patterns, timing, and scoring.

8052 AssemblyAT89S52GPIOKeilPCB Design

Overview

A two-player memory game built around four AT89S52 microcontrollers and custom circuit boards. Players reproduce an LED pattern using matrix keypads while the system manages a countdown and score displays.

System architecture

Two keypad MCUs→ GPIO →Game controller→LED / timer MCU

Each MCU has a dedicated role: game control, player-one input, player-two input, or the LED display. A three-bit active-low selection code communicates the pattern table. Separate GPIO lines signal correct answers.

Implementation

Assembly programs scan the keypads, compare inputs with tables in program memory, and update seven-segment displays. The game controller polls answer lines and advances round state. The documented LED countdown uses Timer0.

Technical challenges

Independent clocks and shared GPIO signals make timing and pin assignment important. The hardware documentation also discusses etched trace width, component connections, and breadboard bring-up before final assembly.

Results and current limits

The public project includes four assembly programs, circuit diagrams, PCB layouts, and assembled-hardware photos. The controller source uses three predefined pattern selections; the portfolio does not imply a random pattern generator. Timing and electrical behavior have not been remeasured for this site.
