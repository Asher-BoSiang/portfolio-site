Bicycle Energy Recovery

Connecting physical energy to useful data. Embedded bike and docking nodes with telemetry and a monitoring backend.

C / C++PlatformIOSPI / I²CPHPMySQL

Overview

A public-bicycle energy recovery prototype combines a hub generator, a bike node, a charging station, and a monitoring backend. Ride data is buffered locally and uploaded after docking.

System architecture

Bike / SD buffer→ docking →Station / Wi-Fi→PHP / MySQL

The bike stores generated energy in a lithium-ion battery. A docking station monitors transfer to a lead-acid battery. A PHP API and MySQL backend support a monitoring webpage and Power BI analysis.

Implementation

Firmware is divided into sensing, logging, time synchronization, networking, and uploading components. Hall sensor pulses provide speed input. A reed switch detects docking, and RTC/NTP synchronization supports time-stamped records.

Technical challenges

The documented work addresses ADC calibration, disconnected operation, and physical docking detection. Local SD storage separates acquisition from network availability.

Results and current limits

The public repository contains firmware, backend endpoints, circuit documentation, and prototype photos. Source inspection confirms a retry loop in the uploader, but it accepts any positive HTTP status as success and uses a blocking retry loop. This portfolio therefore does not claim lossless delivery or production-grade reliability. Energy-recovery performance has not been independently validated here.

Source notes

Based on the public documentation and uploader implementation. Hardware photographs and monitoring examples are available in the source repository.
