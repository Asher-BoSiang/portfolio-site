Intelligent Cockpit HMI

From Linux prototype to QNX. An automotive interface exploring generative visuals and adaptive color.

C++Qt 6QNXLinuxPython

Overview

An automotive HMI developed during an internship at AUO Corporation. Development moved from Python/PyQt prototyping on Linux to a C++/Qt interface on a QNX automotive head unit.

System architecture

Voice / AI prototype→Status controller→Qt / QNX interface

The prototype uses a Python assistant with LangChain and Gemini 1.5 Flash. DALL·E 3 supplies generated backgrounds; color extraction informs interface accents.

Implementation

A C++ implementation of K-means clustering extracts dominant colors. Theme accents follow the generated background within a user-selected light or dark mode. Structured prompts constrain image composition around driving information.

Technical challenges

The central engineering work is the transition between a flexible Linux prototype and the embedded QNX target, alongside maintaining readable visual hierarchy when generated backgrounds vary.

Results

The Linux prototype was migrated to C++ and Qt on a QNX head unit. Production interface assets and source code are withheld under NDA.
