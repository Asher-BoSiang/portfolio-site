Intelligent Cockpit HMI

From Linux prototype to QNX. An automotive interface exploring generative visuals and adaptive color.

C++Qt 6QNXLinuxPython

Overview

An internship project at AUO Corporation, documented publicly as an architecture showcase. The development path moves from Python/PyQt prototyping on Linux to a C++/Qt interface on a QNX automotive head unit.

System architecture

Voice / AI prototype→Status controller→Qt / QNX interface

The documented prototype uses a Python assistant with LangChain and Gemini 1.5 Flash. DALL·E 3 supplies generated backgrounds; color extraction informs interface accents.

Implementation

The public documentation describes a C++ implementation of K-means clustering for dominant-color extraction. Theme accents follow the generated background within a user-selected light or dark mode. Structured prompts constrain image composition around driving information.

Technical challenges

The central engineering work is the transition between a flexible Linux prototype and the embedded QNX target, alongside maintaining readable visual hierarchy when generated backgrounds vary.

Results and disclosure

The repository reports a completed prototype and migration to the QNX target. Source code and actual interface assets are withheld under NDA. Its published images are conceptual schematics, not production screenshots. This portfolio summarizes the public documentation only and does not independently validate accuracy or performance claims.
